## 🚀 Live Overview & Features

- **Interactive Hero Terminal**: Real-time CLI command prompt simulating shell commands (`bio`, `skills`, `projects`, `status`, `curl /api/v1/bio`, `cat bio.json`, `clear`).
- **Command Palette (`Ctrl+K` / `⌘K`)**: Fast keyboard navigation to sections, project specs, and quick contact actions.
- **Project Architecture Inspector & API Sandbox**: Deep-dive modals into architecture schematics with real simulated HTTP responses and timing metrics.
- **Categorized Skills Matrix**: Visual badges with instant filtering across Languages, Backend Frameworks, Databases, Auth & Security, and Tools.
- **Printable Curriculum Vitae**: Clean `@media print` optimized resume view with direct download support.
- **Contact Gateway**: Terminal-styled interactive message dispatch with instant feedback and clipboard copy tools.

## 🛠️ Tech Stack & Architecture

- **Core**: HTML5, Vanilla CSS3 (Custom Design System, Glassmorphism, CSS Custom Properties), Modern ES6+ JavaScript.
- **Zero Heavy Dependencies**: 100/100 performance, instant load times, zero build overhead.
- **Local Server**: Lightweight native Node.js HTTP server.

## 💻 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abdelrahman228/my_portfolio.git
   cd my_portfolio
   ```

2. **Start the local server:**
   ```bash
   node server.js
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
